 프롬프트 고르는 법 — 추가기능에 이미 들어 있는 것부터 쓰세요
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

DRM AI 엑셀 추가기능에는 처음부터 프롬프트 37개가 들어 있습니다.
새로 만들기 전에 목록부터 보세요. 대부분 이미 있습니다.

  보는 곳 :  [데이터] 탭 → [API 메뉴] → [DRM AI v10.0]
             → [일반 기능] → [프롬프트 관리]

  쓰는 법 :  기능을 실행하다가 '프롬프트 가져오기 방식 선택' 창이 뜨면
             [아니오] 를 고릅니다. 목록에서 하나를 고르고
             [Prompt 사용하기] 를 누르면 됩니다.

 이럴 때는 이걸 쓰세요

[ 시험 출제 ]
  5지 선다형 문항을 만들고 싶다
      → 문제 제작_5지 선다형_추가프롬프트
        (이원목적분류표로 만든 '추가 프롬프트'와 함께 씁니다. 실습5 참고)
  자료를 변형해 비슷한 수준의 문제로 다시 내고 싶다
      → 문제 제작_5지 선다형_전과목
  서논술형 문항을 만들고 싶다
      → 문제 제작_사회과_논술형_추가프롬프트
  문항에 넣을 삽화가 필요하다
      → 문제 제작_문제로 이미지 만들기
        (이미지 생성 기능에서 '기본 프롬프트'로 고릅니다)
  낸 문제에 오류가 없는지 보고 싶다
      → 문제 제작_사회과정답과 풀이_오류 가능성표시
        (오류 여부를 맨 앞줄에 적어 주어 하이라이트로 찾기 쉽습니다. 실습6 참고)
  풀이만 필요하고 오류 표시는 없어도 된다
      → 문제 제작_사회과정답과 풀이

[ 채점 ]
  손글씨 답안지를 읽고 루브릭으로 채점
      → 지필 평가 서답형 채점_2026-1-2_OCR및채점
  수행평가(융합주제탐구) 채점
      → 수행평가채점_2026_융합주제탐구
  학생 답안에 피드백을 써 주고 싶다
      → 평가문_학생 답안을 피드백하기

[ 생활기록부 ]
  행동특성 및 종합의견을 쓰고 싶다
      → 평가문_학생부 종합의견
  자유학기 주제선택 특기사항
      → 평가문_2026주제선택
  독서활동을 '도서명(저자)' 형식으로 정리
      → 독서활동 기록 전문가
  써 놓은 세특에 기재 위반이 없는지 점검
      → 학생부 과세특 검토
  독서활동 기재 오류 점검
      → 학생부 독서 활동 점검
  행동특성 기재 오류 점검
      → 학생부 종합 검토
  학생부 파일 하나를 통째로 점검
      → 학생부 파일 단위 검사
  생기부 문장의 맞춤법·음슴체 교정
      → 맞춤법 검사2

[ 자료 만들기 ]
  스캔본·사진에서 글자만 그대로 뽑기
      → OCR_원본 가져오기_수식  (수식이 있는 자료)
      → OCR_원본 가져오기_자필  (학생 손글씨)
      → OCR_원본 가져오기_책    (책 펼침면 여러 장)
      → OCR_4지선택형문제집     (문제집)
  표를 만들고 싶다
      → 테이블 작성_표 형식 자료 이용
      → 테이블 작성_품의서와영수증기반  (지출 품의서 정리)
  퀴즈용 문항을 표로 만들고 싶다
      → 테이블 작성_데이터기반 블루킷문제만들기
      → 테이블 작성_데이터 없이 블루킷 문제 만들기
      → 테이블 작성_영단어 문제 테이블로 만들기_출처_오빠두엑셀
  그림책을 만들고 싶다
      → 그림책만들기
  영어로 번역
      → 번역_영어
  하이라이트용 핵심어 목록 만들기
      → 하이라이트_검증키워드만들기
  엑셀 사용법이 궁금하다
      → 엑셀 전문가_보완

아래 네 개는 실습에서 쓰는 프롬프트입니다. 기본 37개에는 없습니다.
필요하면 [프롬프트 관리] 창에 등록해 두고 쓰세요.

  01_생기부_행동특성_다듬기.txt        실습1에서 쓰는 것
  02_서술형_채점_루브릭.txt            실습4에서 쓰는 것
  03_가정통신문_개별_안내문.txt        실습3을 실제 업무로 확장할 때
  04_출력규약_핵심3줄.txt              어느 프롬프트에나 붙일 수 있는 공통 규약

  등록하는 법
    1. [일반 기능] → [프롬프트 관리]
    2. 파일 내용을 복사해 큰 입력칸에 붙여 넣기
    3. 'Prompt 명칭 입력' 칸에 이름을 적기
    4. [재사용을 위해 Prompt 저장]

  ※ 프롬프트는 100개까지 저장됩니다. 넘으면 오래된 것부터 지우라고 물어봅니다.
  ※ [파일로 내보내기] 를 누르면 목록 전체가 엑셀 파일로 저장됩니다.
     학교를 옮기거나 컴퓨터를 바꿀 때 이 파일 하나만 챙기면 됩니다.
