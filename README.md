## 이 저장소를 사이트로 만드는 법

1. 깃허브에서 **새 저장소(New repository)** 를 만듭니다.
   - 이름은 **영문 소문자와 하이픈**으로 지으세요. 주소에 그대로 드러납니다.
     예 `drm-ai-excel-first40`
   - 한글 저장소 이름도 동작은 하지만 주소가 `%EC%8B%A4%EC%8A%B5…` 처럼 길고 흉하게 늘어납니다.
   - **공개(Public)** 로 만드세요. 무료 요금제에서는 비공개 저장소로 Pages 를 켤 수 없고,
     유료 요금제로 비공개 저장소에 Pages 를 켜더라도 **사이트 자체는 인터넷에 공개**됩니다.
2. **이 폴더 *안의* 파일을 저장소 최상단에 올립니다.**
   - 저장소 첫 화면에서 **Add file → Upload files**
   - 탐색기에서 이 폴더를 열고 **안에 있는 것을 전부 선택해서** 끌어다 놓습니다.
     (폴더 자체를 끌어 놓으면 한 겹 더 들어가 `index.html` 이 최상단에 오지 않습니다.)
   - 아래 **Commit changes** 를 눌러야 실제로 올라갑니다.
   - ⚠️ **이 폴더 바깥의 파일은 절대 올리지 마세요.** 상위 폴더에는 추가기능에 동봉되는
     판매용 프롬프트·시험출제 파일이 함께 들어 있습니다.
   - ⚠️ `.nojekyll` 은 이름이 점으로 시작해 목록에서 안 보일 수 있습니다.
     빠졌다면 **Add file → Create new file** 로 파일 이름만 `.nojekyll` 이라고 적고
     내용은 비워 두거나 한 줄 메모만 적어 커밋하시면 됩니다.
3. 저장소 **Settings → Pages** 로 갑니다.
   - Source: **Deploy from a branch**
   - Branch: **main** / 폴더: **/ (root)** → **Save**
4. 같은 화면에서 **Enforce HTTPS** 를 켭니다.
5. 저장소 위쪽 **Actions** 탭에 배포 작업이 나타납니다. 초록 체크가 뜨면 배포가 끝난 것입니다.
   (Settings → Pages 위쪽에도 "Your site is live at …" 이라고 주소가 나옵니다.)
6. 몇 분 뒤 그 주소로 열립니다. 바뀐 내용이 보이지 않으면 **최대 10분** 기다렸다가
   `Ctrl+F5` (맥은 Cmd+Shift+R) 로 새로 고치세요.

### 올리기 전에 반드시 확인할 것

- [ ] **실제 학생 이름·성적·연락처·학교명이 들어간 파일이 하나도 없는가**
      (이 묶음의 자료는 모두 가상입니다. 선생님 자료를 섞어 올리지 마세요.)
- [ ] **판매 제품의 내용물을 공개해도 되는지 정했는가**
      — 시뮬레이터에는 추가기능에 들어 있는 **프롬프트 4개의 전문**이, `프롬프트_모음`의
      `00_프롬프트 고르는 법.txt` 에는 **내장 프롬프트 30여 개의 이름**이 담겨 있습니다.
      실습에 필요해서 넣은 것이지만, 공개하면 누구나 봅니다. 원치 않으시면 공개 전에 덜어내세요.
- [ ] `.nojekyll` 파일(한 줄짜리)이 저장소 **최상단**에 있는가
      — Jekyll 처리를 꺼서 파일을 있는 그대로 내보내고 배포를 빠르게 합니다.
      (한글 파일명은 Jekyll 이 있어도 대체로 동작하지만, 빌드가 실패하면 사이트 전체가 안 뜹니다)
- [ ] `index.html` 이 저장소 **최상단**에 있는가
- [ ] 링크가 실제로 열리는가 — 배포 뒤 한 번씩 눌러 보세요. 한글 경로 오타는 404 로만 드러납니다

> ⚠️ **한 번 올린 것은 지워도 남습니다.**
> 실수로 올린 파일을 다음 커밋에서 지워도 **예전 커밋에 그대로 남아 누구나 되살릴 수 있습니다.**
> 사고가 나면 파일을 지우는 것으로는 해결되지 않고 **저장소를 삭제하고 새로 만들어야** 합니다.
> 그러니 **첫 커밋 전에** 위 점검을 끝내세요.

> ⚠️ **올리는 순간 전 세계에 공개됩니다.**
> 주소를 아는 누구나 볼 수 있고, 검색 노출을 막는 방법도 첨부 파일(`.xlsx`, `.pdf`, `.txt`)에는 통하지 않습니다.
> **완전히 공개된다는 전제**로만 쓰세요. 제한 배포가 필요하면 학교 LMS 나 구글 드라이브를 쓰시는 편이 낫습니다.

## 사용 환경

- **시뮬레이터** — 최신 크롬 · 엣지 권장. 휴대폰·태블릿에서도 열리지만, 칸을 끌어 범위를 고르는 연습은 PC 가 수월합니다. 설치할 것도, 요금도 없습니다.
- **실습 엑셀** — 윈도우 · 엑셀 · **DRM AI 엑셀 추가기능 설치** · [교사를 위한 올인원 도우미] **메일 인증**(회신까지 보통 1~2일, 체험판은 통과하지 못합니다) · **본인 API 키 입력**(리본 [안내 및 설정] → [API 키 입력(사용자)])이 되어 있어야 실제로 돌아갑니다. 메일 인증은 AI 실행 메뉴와 [API 키 입력(사용자)] 에 필요하고, [일반 기능]은 인증 없이 됩니다. Gemini 는 **먼저 선불 충전**한 뒤 `AQ.` 로 시작하는 새 키를, OpenAI 는 결제 수단을 등록한 뒤 키를 넣으세요.

## 자주 묻는 질문

**Q. 엑셀을 열었더니 "보호된 보기" 라고 나옵니다.**
A. 인터넷에서 받은 파일이라 윈도우가 붙인 표시입니다. 위쪽 노란 띠의 **[편집 사용]** 을 누르세요.
그래도 안 되면 파일을 오른쪽 클릭 → [속성] → 아래쪽 **[차단 해제]** 에 체크하세요.

**Q. 실습3 이 안 됩니다.**
A. 실습3 은 폴더 안 파일 이름을 실제로 바꿔 보는 미션이라 연습용 파일이 폴더째 있어야 합니다.
**낱개가 아니라 ZIP 으로** 받아 압축을 푸세요. (실습6 은 PDF 하나만 받으셔도 됩니다.)

**Q. 시뮬레이터에서 하던 것이 사라졌습니다.**
A. 진행 상태는 그 컴퓨터의 그 브라우저에만 남습니다. 다른 PC · 시크릿 창 · 기록 삭제 뒤에는 처음부터 시작합니다.

**Q. 고친 내용이 사이트에 안 보입니다.**
A. 최대 10분 걸립니다. 그 뒤에도 그대로면 `Ctrl+F5` (맥은 Cmd+Shift+R) 로 강제 새로 고침 하세요.
